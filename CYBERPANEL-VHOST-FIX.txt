# CyberPanel 500 fix — vHost Conf (rakushopbd.com)

## আগে VPS SSH-এ চেক করুন (Mac browser এ 127.0.0.1 নয়!)

curl -i http://127.0.0.1:3001/api/db-check

→ JSON {"ok":true,...} = Node ঠিক, শুধু vHost proxy ঠিক করতে হবে
→ connection refused = pm2 restart rakushopbd

---

## vHost Conf — এটা ADD করুন

CyberPanel → Websites → List Websites → rakushopbd.com → vHost Conf

ফাইলের শেষে (বা rewrite block এর বদলে) যোগ করুন:

extprocessor rakushopbd_node {
  type                    proxy
  address                 127.0.0.1:3001
  maxConns                100
  pcKeepAliveTimeout      60
  initTimeout             60
  retryTimeout            0
  respBuffer              0
}

context / {
  type                    proxy
  handler                 rakushopbd_node
  addDefaultCharset       off
}

---

## পুরনো rewrite থাকলে REMOVE করুন

এই block থাকলে delete করুন (500 এর কারণ হতে পারে):

rewrite  {
  ...
  RewriteRule ^(.*)$ http://127.0.0.1:3001/$1 [P,L]
}

extprocessor + context একসাথে rewrite [P] দুটোই রাখবেন না।

/usr/local/lsws/bin/lswsctrl restart
